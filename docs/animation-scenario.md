# Dala — оригінальний анімаційний референс

Відновлено зі збереженої версії `5a6b95e`. Це дослідницька сторінка, щоб побачити, як працював оригінал. Поточний документний прототип збережений у `/private/tmp/dala-before-original-20261116-225152/workspace.tar.gz`; поруч лежать `changes.patch` і `status.txt`. Невикористані модулі документів залишені в репозиторії, але головна сторінка їх не завантажує.

## Темна палітра FMB

Усі активні анімації використовують шкалу **Deep Navy `#041e42` → Classic Champagne `#d6be93` → Warm Ivory `#f6f2e9`**. Navy є початком гамми та фоном сторінки. Фінальний shader після bloom/depth blur бере палітру з CSS-змінних; віньєтка множить яскравість, не відтинаючи слабкі частинки. Цей прохід охоплює обидві WebGL-сцени, включно з переднім шаром, зерном і фігурами інвесторів. CSS-анімації меню, кнопок, завантажувача та масок узгоджені з тією самою темою.

Canvas розташований позаду контенту всередині ізольованого `body`; фон `body` прозорий, а Navy-фон задано на `html`. Поточне приховування текстів секцій та всі таймінги й траєкторії збережені.

## Де дивитися реалізацію

- `app/page.tsx` — початкова послідовність секцій і текстів.
- `legacy/2601.cjs` — збережений розпакований рушій: Three.js/WebGL, GSAP, GPU-симуляція, навігація та карусель.
- `app/ScriptLoader.tsx` → `legacy/entry.cjs` → `startDala()` — запуск один раз на документ, включно з React StrictMode. `window.__DALA_RUNTIME__.state` відкриває стан для дослідження; `status` показує `starting`, `running` або `error`.
- `public/css/style.css` — оригінальна адаптивна верстка та CSS-ефекти. `animate-from` у JSX задає параметри появи текстів.

## Ресурси та точність відновлення

- Початкові текстури `pos-33.exr`, `cd-33.png`, `sc-33.png` і моделі `py-*.glb` збережені локально.
- PPNeueMontreal у Git відсутній. Запит до старої адреси dala.ai повернув 2 байти замість шрифту. Локально підключено Inter Variable з офіційного `rsms.me`, з ліцензією `public/fonts/Inter-LICENSE.txt`; CSS зберігає ваги 200/400/600. Для точного шрифту потрібно надати оригінальні ліцензовані файли.
- Портретів `/images/team/*` та мобільних зображень `/images/investors/*` у вихідному репозиторії немає. Імена та початкові шляхи збережені, фотографії людей не вигадані. Ці частини не можуть вважатися візуально відновленими повністю без файлів.
- Початкові адаптивні розміри та брейкпоінти взяті з CSS оригіналу; нормалізовані виміри опису стилю не підміняють їх.
- Збережено поведінку оригінального рушія; окремої підтримки reduced motion він не має.
- Аналітика та Intercom не запускаються в цьому дослідницькому референсі.

## Перевірка

Production build і запуск/перезапуск dev-сервера не виконуються. Результати фінальних легких перевірок та перегляду на вже запущеному сервері наведені у відповіді до цієї зміни.
